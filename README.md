# Zone4Wall Studio V4 — XR Interface

V4 is a browser-based immersive fashion-studio interface inspired by the previous VR screenshot.

## New direction
- VR/XR HUD rather than a conventional website
- Fashion-material "orbital vortex" instead of an Earth/globe-like sphere
- Actual WebXR immersive-VR button using Three.js WebXR support
- Interactive material scanner
- Floating material particles
- HUD coordinates, system status and XR session status
- Responsive layout
- GitHub Pages ready

## Important for actual VR
The site must be served over HTTPS for WebXR in normal browser deployments. GitHub Pages provides HTTPS.

The `file://` version can still show the 3D interface, but the actual `ENTER XR` headset session generally requires a secure web context and a compatible WebXR device/browser.

## Current material list
Viscose, Brushed Fleece, Sherpa/Fur Fleece, Stretch Crepe, Stretch Satin, Velvet.

GSM/composition is intentionally not hard-coded because final specifications should be confirmed for each development.
